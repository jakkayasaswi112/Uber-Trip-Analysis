# Uber Trip Analysis

This project is about analyzing Uber trip data and predicting weekly trip demand using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## What I Did

- Analyzed Uber pickup data from April to September 2014
- Checked trip patterns based on hour, day and weekday
- Analyzed weekly trip counts
- Built a Linear Regression model to predict weekly trips
- Evaluated the model using MAE, RMSE and R² score
- Saved the trained model using Joblib

## Result

The model predicted around **222,841 trips** for the next week in the project dataset.

## Project Structure

- `data/` – Dataset files
- `notebooks/` – Analysis and model development
- `models/` – Saved machine learning model
